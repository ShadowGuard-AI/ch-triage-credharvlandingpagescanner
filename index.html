One URL, Fetched Once

Given a URL, the tool downloads the HTML content of the landing page. That single sentence is the whole intake of the tool as documented: one user supplied URL, one page fetched. This station adds no crawls, no link following, and no site wide scanning, none of which the source claims.

Credential Fields

On that page the scanner looks for input fields for username and password, and the form submission endpoints associated with them. The two field kinds carry their own markers on this transect, since a page can hold many forms and the source singles out credential fields as the ones that matter here.

Where the Form Posts

The scanner reports potentially malicious form actions, and in the fuller phrasing it flags login forms that post off origin or to a non web scheme. Those two destinations, away from the page's own origin and away from ordinary web schemes, are the documented tests. No other test is listed, and this station invents no checks for page text, brand imitation, certificates, or redirects.

The URL Argument Is Not Named

The source describes a tool driven by a supplied URL, yet the usage form never names a URL argument, so how the address is handed over is not documented. That gap stays visible rather than being patched with a plausible looking example.

Listed Without a Description

Two of the three markers on this shoal, -v and -o, are listed without a description, so a reader cannot tell from the document what either one does. No meaning is guessed for -o as an output path, however common that pattern is elsewhere.
